# AMIYA - Friendship Website
12 pages, HTML5/CSS3/vanilla JS. Java 21, Maven WAR, Tomcat 9.

    mvn clean package        # banega target/amiya.war
    cp target/amiya.war $TOMCAT_HOME/webapps/
    open http://localhost:8080/amiya/

Pages ka content `src/main/webapp/*.html` mein edit karo. Hero photo: `assets/img/hero.jpg`.
